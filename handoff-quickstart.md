## Superuser recovery (on takeover/recovery)

Dunking Sheep **2.15.0** gates every destructive or affecting-others operation
behind a superuser allowlist. On takeover, from the **VP pane**:

```sh
dunkingsheep superuser recover          # adds $HERDR_PANE_ID + "VP of agentry"
dunkingsheep superuser status           # confirm superuser: yes
```

Only superusers may close panes/tabs/workspaces, stop the daemon, manage dunks,
spawn agents, or use the raw herdr passthrough. Everyone else communicates
through the inbox and task queue and may type only into their own pane. Even a
superuser must pass `close --force` to close the pane/tab/workspace it is
running in. The allowlist is `~/.config/dunkingsheep/superusers.json` (0600);

### The port harness and `pr_ega` (the day's biggest structural result)

`RES 00BA:16EC` is the biggest multiplier on the board (~18 handlers depend on it) but Claude measured it as **~88% port-bound** (direct I/O 1,994 B / 31.6%; transitively port-bound 3,548 B / 56.2%; pure only 770 B / 12.2%), so pure modelling could never reach it. Instead of giving up, the harness was built:

- **Spec:** `docs/re/RES_00BA_16EC_PORT_HARNESS.md` — trace format (8-byte header, 16-byte preamble, 32-byte events: OUT8/16, IN8/16, INS/OUTS, INT-enter/leave, terminate, overlay-trap, with a 20-byte register block), plus an explicit **LICENCE BOUNDARY** section (DOSBox-X, Unicorn and binutils stay external tools; no GPL source/headers/binaries vendored or linked; C hardware models come from public documentation only — the repo is **PUBLIC and UNLICENSED**, so this matters).
- **Proven in place (PR #1038):** `0709:0000` EGA register reset (113 B/58 insns, 18 `OUT DX,AL`) — 1,156 ordered OUT events matched under Unicorn `UC_HOOK_INSN`, and under DOSBox-X each case ran **both** plain (full state) **and** under a **guest-side INT 1 single-step tracer**, with all **576** traced OUT events matching the C port environment (`pr_port_env`, `port_env.h`). No emulator code involved; the tracer is a guest-side two-run instrument with IVT hooks inside our synthetic COM.
- **`pr_ega` (PR #1045):** a C model of the EGA planar pipeline (SEQ/GC ports incl. word OUTs, 4 planes, latches, write modes 0–2 with rotate, set/reset, ALU, bit mask, map mask, read modes 0–1), written from public register docs, **validated against DOSBox-X `machine=ega` mode 0Dh** with two random 3,000-operation scripts (OUTs, A000 writes/reads) and **every read and plane byte equal**. Hardware model → **no strict credit**, but it makes video-memory correctness checkable in C, which unlocks the rect fill `0709:00B7` and the **`01DF` EGA blitter (1,036 B — the largest single port-bound body)**. Because it is committed, the blitter line no longer depends on any one lane.
- With the harness, **5,752 of 6,312 B (91.1%)** of the `16EC` closure becomes testable; what remains is the **INT 3Fh overlay-trap class** (560 B, gets PENDING partials) plus an indirect text-driver call and replayed timing reads. A related correction: `0A32:000B` was miscounted as pure but is the Turbo Pascal DOS unit's `Intr(IntNo,Regs)` (no INT/IN/OUT opcode, but it pushes FLAGS + CS:0045, pushes the IVT vector and RETFs into the handler), so it is interrupt-bound — the tracer records that RETF-into-vector as an INT event (PR #1044).
